# Ignacio Ferrán — Martillero (demo)

Sitio de demostración de un martillero y corredor público: próximos remates con cuenta regresiva y condiciones, propiedades con filtros y favoritos, servicios, cómo funciona un remate y formulario de tasación por WhatsApp.

Los datos son ficticios. Para cambiar remates o propiedades, editá los arreglos `LOTES` y `PROPS` en `js/app.js`.

Fotos: Unsplash. Diseño y desarrollo: [Bether Studio](https://bether-studio.com/).
